Jyotirling Shivmath — Video Upload

किसी भी कंप्यूटर से अपनी मूल वीडियो को सीधे इस रिपॉज़िटरी के GitHub Release में अपलोड करें। यह पेज वीडियो को अपने सर्वर पर नहीं रखता।

सुरक्षा: Fine-grained GitHub token केवल इसी रिपॉज़िटरी के लिए और Contents: Read and write अनुमति वाला रखें। Token केवल इस ब्राउज़र टैब की memory में रहेगा; यह पेज उसे सेव या कहीं भेजकर लॉग नहीं करता। काम पूरा होने पर token field खाली कर दें।
GitHub Release की प्रति फ़ाइल सीमा 2 GiB से कम है। इंटरनेट कटने पर इस पहले संस्करण में upload को फिर से शुरू करना पड़ेगा।

अपलोड सफल हुआ। अब Create YouTube Shorts workflow खोलकर Run workflow करें और वही release tag डालें।
